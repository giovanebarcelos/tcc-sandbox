# Aula 01B — Modelos para o agente de IA

Arquivos-modelo da **Aula 01B (IA Assistida em Teoria da Computação e Compiladores)**. Copie para a pasta do seu projeto:

| Arquivo | Para quê | Slide da Aula 01B |
|---|---|---|
| `opencode.json` | Modelo gratuito (`:free`) e permissões: comandos com `ask`, `git push` negado. **Nunca** coloque a chave de API aqui | 14 e 31 |
| `AGENTS.md` | Memória do projeto para o agente, com a regra "teste com cadeias antes de aceitar". Cresce a cada etapa | 33 |

Confira a configuração com `opencode debug config`. A chave da OpenRouter fica em `~/.local/share/opencode/auth.json`, fora do projeto.
